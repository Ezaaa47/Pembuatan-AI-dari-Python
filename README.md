
# 🤖 Smart Daily Assistant

AI Personal Assistant berbasis Python dan Google Gemini.

## Tentang Aplikasi

Smart Daily Assistant adalah aplikasi Artificial Intelligence
yang dirancang untuk membantu aktivitas sehari-hari.

## Fitur

- AI Chat Assistant
- Asisten Belajar
- Pembuat Laporan
- Perangkum Teks
- Penerjemah Bahasa
- Asisten Coding
- Riwayat Percakapan
- Dashboard Statistik

## Teknologi

- Python
- Streamlit
- Google Gemini API
- HTML
- CSS

## Instalasi

1. Clone repository.
2. Buat virtual environment.
3. Instal requirements.
4. Atur API Key Gemini.
5. Jalankan aplikasi.

## Menjalankan Aplikasi

```bash
streamlit run app.py
```
